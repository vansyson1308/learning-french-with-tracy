### Tracing attempt (§10)

Searched: the complete upstream history (11 commits), README, the only
LICENSE file (MIT, code), all tracked text files for TTS/voice/license
mentions, the audio manifest header ("Generated by scripts/gen-audio.ts"),
and the binary tags of every language directory. Result: the recordings
were produced by an unpublished script from an unnamed text-to-speech
service; **no license or terms for the audio exist anywhere**. The
repository's MIT grant covers the code; it does not establish that the
generator's provider permitted redistribution of its output. That is an
unproven redistribution right, so under §9 the recordings do not ship.

## Pipeline guarantees

- Voices pinned by double-download SHA-256 (`content/audio/pack-audio-manifest.json`); MODEL_CARDs preserved verbatim under `content/audio/model-cards/`.
- License gate: allow CC BY 4.0 / CC BY-SA 4.0 / CC0; deny AGPL, GPL, NC, ND; a card that matches nothing excludes the voice.
- Every clip: technical QA (duration, level, edge silence, speaking-rate band per language) and an ASR audit in the clip's language; strict QA gates the generate run.
- Assets are content-addressed (`sha256(course, voice, text, rate, pipelineVersion)`), the runtime manifest is regenerated as a whole, and `content/audio/legacy-baseline.json` is re-blessed to the generated set so CI verifies every shipped file.
- No paid service, no runtime model, no network at runtime.
