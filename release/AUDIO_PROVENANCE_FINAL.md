### Tracing attempt (§10)

Searched: the complete upstream history (11 commits), README, the only
LICENSE file (MIT, code), all tracked text files for TTS/voice/license
mentions, the audio manifest header ("Generated by scripts/gen-audio.ts"),
and the binary tags of every language directory. Result: the recordings
were produced by an unpublished script from an unnamed text-to-speech
service; **no license or terms for the audio exist anywhere**. The
repository's MIT grant covers the code; it does not establish that the
generator's provider permitted redistribution of its output. That is an
unproven redistribution right, so under §9 the recordings do not ship.

## Pipeline guarantees

- Voices pinned by double-download SHA-256 (`content/audio/pack-audio-manifest.json`); MODEL_CARDs preserved verbatim under `content/audio/model-cards/`.
- License gate: allow CC BY 4.0 / CC BY-SA 4.0 / CC0; deny AGPL, GPL, NC, ND; a card that matches nothing excludes the voice.
- Every clip: technical QA (duration, level, edge silence, speaking-rate band per language) and an ASR audit in the clip's language; strict QA gates the generate run.
- Assets are content-addressed (`sha256(course, voice, text, rate, pipelineVersion)`), the runtime manifest is regenerated as a whole, and `content/audio/legacy-baseline.json` is re-blessed to the generated set so CI verifies every shipped file.
- No paid service, no runtime model, no network at runtime.

## Audio pipeline v2 — per-language provenance (P3b)

Engines (pinned in `content/audio/engines.json`, used on the runner only):
Piper classic `piper-tts` 1.2.0 (MIT; voices from rhasspy/piper-voices
v1.0.0, licence per voice dataset), Kokoro-82M (Apache-2.0 model and
`kokoro` 0.9.4 package, repository revision pinned), MeloTTS (MIT library
pinned by commit; MIT per-language models pinned by revision). ASR audit:
faster-whisper 1.0.3 (MIT) and FunASR 1.4.16 + SenseVoiceSmall (custom model
licence — an audit tool, never shipped) for zh/ja/ko; Vietnamese is audited
with faster-whisper (SenseVoiceSmall has no Vietnamese — corrected in P3c). Licence gate v2:
allow CC0 / public domain / CC BY 4.0 / CC BY-SA 4.0 / Apache-2.0 / MIT for
the dataset or model licence; deny GPL/AGPL/NC/ND/OpenRAIL/RAIL/Gemma/CPML
and unverifiable cards. Clips of pipelineVersion ≥ 2 are loudness-normalised
(EBU R128, −18 LUFS integrated, −1.5 dBTP); French stays at version 1.

**Encoding (P3f).** pipelineVersion 1–2: 22.05 kHz mono MP3 at 64 kbps. From
pipelineVersion 3 (the default for every language except French) speech is
encoded at **32 kbps mono** (`content/audio/engines.json`
`encoding.mp3KbpsFromVersion`), which halves the bundle for spoken words and
sentences. French files are untouched (version 1, frozen keys). The lexicon
layer voices only the syllabus words (`content/<lang>/lexicon/syllabus.json`),
not every lexeme and example; the rest of the dictionary uses the device
voice. Each language's bundled speech is capped at **12 MB** (`audio:check`
fails above it); `content/reports/audio-size.json` records the sizes.
Playback of the 32 kbps files by expo-audio is part of the RC4 device
checklist (`release/DEVICE_ACCEPTANCE.md`) — **not yet observed on a device**.
Beyond four bundled languages see `release/ASSET_DELIVERY.md`.
