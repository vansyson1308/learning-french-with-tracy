# Closed-test tracker — 12 testers × 14 consecutive days (D-16)

Requirement for a new personal Play account (VERIFY IN CONSOLE — the app
dashboard states the current rule): **at least 12 testers opted in for 14
consecutive days** before production access can be requested. D-16 does not
request production before v1.0; the 14 days still run now so the requirement
is met when v1.0 is ready.

**No personal data in this file.** Tester emails live only in the Play
Console email list. Use a nickname or initials here (`T01`… or "Lan A.").
